# EAN Marketing

Android sales and inventory app for EAN Marketing.

## Project status

This repository is being prepared for an Expo React Native Android app connected to Supabase. The app is intended for direct APK installation, not Play Store publication.

## Planned features

- Admin and user sign-in
- Product catalog with photos and search
- Inventory tracking
- Sales recording with stock deduction
- Expenses (admin only)
- Sales and profit summaries
- Admin-managed user accounts

## Setup notes

1. Create a Supabase project.
2. Apply the database schema and policies supplied for this app.
3. Configure the app's Supabase project URL and publishable key in a local environment file.
4. Install dependencies and run the Expo project.
5. Build an Android APK with an Expo EAS preview build.

Never put a Supabase secret/service-role key in the Android app or commit private keys to this repository.

This project is under development. It is not yet a tested or installable APK.
